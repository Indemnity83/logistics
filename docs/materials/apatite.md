# Apatite

**Apatite** is a gem obtained from mining [apatite ore](apatite-ore.md). It's used for apatite valves.

## Obtaining

**Mining:**
- Mine [Apatite Ore](apatite-ore.md)
- Drops 1× Apatite (more with Fortune)

**Crafting (from block):**
- 1× Apatite Block → 9× Apatite

## Usage

**[Kiln](../automation/kiln.md) Crafting:**
- [Apatite Valve](valve-apatite.md) - 5× apatite required

**Storage:**
- 9× Apatite → Apatite Block

## Tips

- Gem-type material (like diamond/emerald)
- Fortune enchantment increases drops
- Needed for Tier 3 valves
- Requires premium fuel (blaze rod/lava) to craft valve
