The '''Crafter Module''' is a [[Chassis Logistics Pipe]] module that enables '''automated crafting''' within a chassis pipe. When installed, the chassis can fulfill network requests for a specific crafted item by sourcing ingredients from the network and performing the crafting operation.

Three mark variants exist (MK1/II/III), with higher marks supporting more complex recipes or faster crafting cycles.

==Behavior==

When installed in a [[Chassis Logistics Pipe]], this module registers a crafting recipe with the network. When the network receives a request for the output item, this module requests the necessary ingredients from the network's providers and performs the crafting operation, delivering the result to the requester.

'''Key features:'''
* Registers a crafting recipe with the logistics network
* Automatically requests ingredients from [[Provider Logistics Pipe|Provider Logistics Pipes]] or [[Provider Module|Provider Modules]]
* Delivers crafted output back into the network or to a configured destination
* Multiple Crafter Modules in different chassis pipes can produce the same item — the network balances the load

==Tips==

* Combine Crafter Module + Provider Module in a single MK2 chassis for a complete crafting station that both produces and provides items
* Chain crafting modules for multi-step production — one module produces intermediate items that another consumes
* MK3 is worthwhile for high-demand recipes where speed is critical
* Place the chassis adjacent to a crafting inventory buffer for ingredient staging
