# Wooden Gear

The **Wooden Gear** is a basic crafting component used to create early-game machines and engines. It's the foundation of the gear progression system.

## Progression

Wooden Gears represent the first tier of crafting materials:
- **Wooden Gear** → Basic tier (this item)
- [Stone Gear](stone-gear.md) → Stone tier
- [Iron Gear](iron-gear.md) → Mid tier
- [Copper Gear](copper-gear.md) → Mid tier
- [Diamond Gear](diamond-gear.md) → Advanced tier

## Tips

- Craft from readily available sticks
- Needed for first engine
- Simple 1:1 stick-to-gear ratio (4 sticks = 1 gear)
- Stock up for early automation
