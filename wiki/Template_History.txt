A row of the version-history table (Version | Changes). Each call is one row; group several into one
table with <code>head=1</code> on the first and <code>foot=1</code> on the last. A single-row history
sets both. Plain wikitext (uses the {{((!))}} / {{())!))}} table helpers); styling lives in
[[Template:History/styles.css]].

Usage (newest version first):
 {{History|head=1|v0.2.0|Added eight more dye colors.}}
 {{History|foot=1|v0.1.0|Added '''Marking Fluid'''.}}

Parameters:
 1 / version  — the version string
 2 / changes  — what changed in that version (wikitext allowed)
 head / foot  — open / close the table
