'''Marking Fluid''' is a color-coding tool that prevents [[Copper Transport Pipe|Copper Transport Pipes]] from connecting to each other. Use it to segment networks and run multiple independent pipe systems side-by-side. It comes in all '''16''' Minecraft dye colors, each crafted with its matching dye.

== Obtaining ==

=== Crafting ===

Each colored marking fluid is crafted '''shapeless''' from a Water Bottle plus the matching dye — one recipe per color, all 16 Minecraft dye colors:

== Usage ==

Marking fluid segments a network by color. A marked [[Copper Transport Pipe]] only connects to other pipes of the same color, so independent systems can run side by side — a cleaner alternative to physically separating them with blocks. It works only on [[Copper Transport Pipe|Copper Transport Pipes]], and unlike an [[Item Filter Pipe]] it prevents a physical connection rather than sorting items.

=== Applying ===

Right-click a [[Copper Transport Pipe]] with marking fluid to color it:

# Craft marking fluid in the desired dye color
# Right-click the copper pipe with the marking fluid
# The pipe takes on the dye color

=== Removing ===

Sneak + right-click a marked pipe with an empty hand to clear it. The pipe returns to its unmarked state and connects to any pipe again.

=== Connection rules ===

* '''Same color''' — pipes connect to each other, forming networks isolated by color.
* '''Different colors''' — pipes do not connect, keeping colored networks separate.
* '''Unmarked''' — pipes connect to all pipes regardless of color, and can bridge between colored networks.

== Data values ==

=== ID ===

Marking Fluid is a set of 16 dyed items — <code>logistics:pipe/&lt;color&gt;_marking_fluid</code> for each dye color (white, orange, magenta, light_blue, yellow, lime, pink, gray, light_gray, cyan, purple, blue, brown, green, red, black), with translation key <code>item.logistics.pipe.&lt;color&gt;_marking_fluid</code>.
