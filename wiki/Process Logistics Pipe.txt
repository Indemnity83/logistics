== Usage ==

The Process Logistics Pipe automates a machine such as a furnace, blast furnace, or [[Kiln]]. It feeds raw materials from the network into the machine's input and extracts finished output back into the network, mapping input/output faces and watching machine state so it never overfills. Pair it with [[Provider Logistics Pipe|providers]] for materials and [[Requester Logistics Pipe|requesters]] to pull results.

== Power ==

Like every [[Logistics Pipes|logistics pipe]], it draws [[RF Energy|RF]] through a [[Power Junction]] — it renders '''green''' while powered and '''red''' when the network has no charge, in which case routing stops and items in transit drop.
