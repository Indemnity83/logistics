This template renders a single inventory item: its grid icon, with an optional count.

The icon links to the item's page via [[Module:ItemLink]]: mod items link to their local wiki
page, while vanilla Minecraft items link out to the [https://minecraft.fandom.com/ Minecraft Wiki]
(so a recipe's vanilla ingredients are still clickable). The mod/vanilla decision is a table lookup,
not an {{#ifexist:}}, so it stays off the page's expensive-parser-function budget.

Usage:
 {{Grid|Tin Ingot}}      -> icon linking to [[Tin Ingot]] (a mod item)
 {{Grid|Cobblestone}}    -> icon linking to the Minecraft Wiki (a vanilla item)
 {{Grid|Tin Ingot|8}}    -> icon + "×8"

Image lookup: it looks for [[File:Grid <name>.png]]. If that image has not been
uploaded yet, it falls back to a plain text link (local or Minecraft Wiki, same rule),
so the template degrades gracefully on a fresh wiki.
