Renders a [[Refinery]] recipe: a '''fluid''' input on the left (its animated ''Fluid <name>.gif'',
falling back to a {{Grid}} swatch) with the millibuckets consumed beside it, an arrow, the '''fluid'''
output top-right with the millibuckets produced, and an optional '''chance byproduct''' item in a
slot below it with its drop chance — the way the machine distills one fluid into another and vents a
solid byproduct. The byproduct slot is always shown (empty when a recipe has none) so the machine's
second output is clear. Styling reuses [[Template:Grid Crafting Table/styles.css]] for the panel,
slots, and arrow, plus [[Template:Grid Refinery Table/styles.css]] for the mB amounts and chance.

Usage:
 {{Grid Refinery Table
 |Input=Crude Oil |InputAmount=200 |Output=Fuel Oil |Amount=150
 |Byproduct=Tar |ByproductChance=50%
 }}

Parameters:
 Input           — the input fluid (rendered as its Fluid <name>.gif, else a {{Grid}} swatch)
 InputAmount     — millibuckets consumed, e.g. "200"
 Output          — the resulting fluid
 Amount          — millibuckets produced, e.g. "150"
 Byproduct       — a secondary chance item output (optional)
 ByproductChance — its drop chance, e.g. "50%" (optional)

Depends on [[Template:Grid]].
