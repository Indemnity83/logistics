The '''Terminus Module''' is a [[Chassis Logistics Pipe]] module that accepts filtered items from the [[Pipe Networks|logistics network]] into an adjacent inventory, at a lower [[Modules#Sink priority|sink priority]] than an [[ItemSink Module]].

== Obtaining ==

=== Crafting ===

{{Crafting|head=1|foot=1|showname=0
|A1=Black Dye |B1=Iron Gear |C1=Purple Dye
|A2=Redstone |B2=Blank Module |C2=Redstone
|A3=Purple Dye |B3=Redstone |C3=Black Dye
|Output=Terminus Module
}}

The matching [[Chipsets|chipset]] can replace the gear — use an [[Iron Chipset]] in place of the [[Iron Gear]] to craft it with a [[Sequential Fabricator]].

== Usage ==

The Terminus Module is a filter-only sink. Configure up to 9 item types with a [[Wrench]]; network items of those types are routed to this chassis and deposited into an adjacent inventory.

* Accepts only items that match its filter.
* Cannot be set as a default route, so it never catches unfiltered items.
* Sits at priority 4 on the [[Modules#Sink priority|sink priority]] ladder: an [[ItemSink Module]], [[Polymorphic ItemSink Module]], [[Mod-Based ItemSink Module]] or [[Basic Logistics Pipe]] that accepts the same item takes it first. It outranks only the [[Enchantment Sink Module]] and default routes.

Use it for overflow storage: items go to it only when no higher-priority sink accepts them or has room.
