The '''Passive Supplier Module''' is a [[Chassis Logistics Pipe]] module that keeps an adjacent inventory stocked by '''intercepting matching items already traveling through the [[Pipe Networks|logistics network]]'''. It never places its own orders — it acts as a network '''sink''', grabbing in-transit items whose type matches a configured supply slot while that item's stock sits below the target.

Because it never requests, it adds no ordering load to the network and draws no power to operate. It is the counterpart to the [[Active Supplier Module]], which actively orders replenishment.

== Usage ==

When installed in a [[Chassis Logistics Pipe]], this module registers as a network sink for the items configured in its GUI. As matching items flow through the network — sent by [[Provider Module|Providers]], crafters, or active suppliers — it pulls them into the adjacent inventory until the target stock level is reached.

* Never places orders — only intercepts items already in transit.
* Accepts an item only while the inventory is below the configured target for that item.
* No power cost to operate (it does not actively request).
* Re-syncs its accepted-item list periodically and whenever connections change.

=== Configuration ===

Configure the items and target quantities via the module GUI in the chassis (use a [[Wrench]]).

Use it for backup stockpiles or low-priority storage that fills opportunistically from network traffic, and reach for an [[Active Supplier Module]] instead when you need guaranteed replenishment rather than opportunistic fills.
