# Blank Module

The **Blank Module** is the base crafting component for all [modules](index.md). It has no behavior on its own — it is only used as an ingredient in module recipes. Every module type is crafted by combining a Blank Module with specific materials in the crafting grid.

## Usage

The Blank Module is consumed when crafting any other module type. Craft it in advance so you have a supply ready when building out your [Chassis Logistics Pipe](../pipes/chassis-logistics-pipe.md) setup.

## Tips

- Craft Blank Modules in batches — each module type requires one, and a fully loaded MK5 chassis needs 5
- Paper is plentiful from sugar cane farms; gold nuggets come from gold ingots (9 nuggets per ingot)
- Store a stack of Blank Modules near your logistics crafting area to streamline module production
