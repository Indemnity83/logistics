Renders one row of the '''Data values''' ID table (Name / Namespaced ID / Translation key). Stack
one {{ID}} call per row: '''head=1''' on the first (opens the table + header), '''foot=1''' on the
last (closes it). A single-row table sets both. Pass the ID and translation key as literal strings —
take the key from the lang file, don't infer it.

Usage:
 {{ID|head=1|foot=1|logistics:core/tin_ingot|item.logistics.core.tin_ingot}}

 {{ID|head=1|logistics:core/tin_ore|block.logistics.core.tin_ore|name=Tin Ore}}
 {{ID|foot=1|logistics:core/deepslate_tin_ore|block.logistics.core.deepslate_tin_ore|name=Deepslate Tin Ore}}

Parameters:
 1, 2   — namespaced ID and translation key for this row
 name   — display name (defaults to the page title)
 head   — set on the first row to open the table + header
 foot   — set on the last row to close the table
