The '''Polymorphic Sink Module''' is a [[Chassis Logistics Pipe]] module that accepts '''any item type that already exists''' in an adjacent inventory. It dynamically fills existing partial stacks rather than requiring a preconfigured item type like the [[Item Sink Module]].

The matching [[Chipsets|chipset]] can replace the gear — use an [[Iron Chipset]] in place of the [[Iron Gear]] to craft it with a [[Sequential Fabricator]].

== Usage ==

When installed in a [[Chassis Logistics Pipe]], this module scans the adjacent inventory for existing item types. Any network item that matches a type already present in that inventory is accepted by this module and deposited to fill or extend those stacks.

* Accepts any item type that already has at least one item in the adjacent inventory.
* Dynamically updates as the adjacent inventory contents change.
* Will not accept items for which the adjacent inventory has no existing stack.
* Ideal for refilling partially depleted storage without configuring each item type manually.

Seed the adjacent inventory with one of each item type you want it to accept and the module handles the rest, keeping regularly-replenished buffer chests topped off. Combine it with an [[Item Sink Module]] in the same chassis for a two-tier strategy: polymorphic for the bulk, specific sinks for overflow.
