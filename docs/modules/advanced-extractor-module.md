# Advanced Extractor Module

The **Advanced Extractor Module** is a [Chassis Logistics Pipe](../pipes/chassis-logistics-pipe.md) module that extracts items from an adjacent inventory with **advanced filter and scheduling control**. Compared to the standard [Extractor Module](extractor-module.md), it supports more complex filter configurations and can extract based on conditions.

Three mark variants exist (MK1/II/III), each upgrading extraction throughput.

## Variants

| Variant | Gear | Notes |
|---------|------|-------|
| Advanced Extractor Module (MK1) | Iron Gear | Advanced filtering, standard throughput |
| Advanced Extractor Module MK2 | Gold Gear | Advanced filtering, higher throughput |
| Advanced Extractor Module MK3 | Diamond Gear | Advanced filtering, maximum throughput |

## Behavior

The Advanced Extractor Module extracts items with more powerful filtering than the standard [Extractor Module](extractor-module.md). It supports larger filter lists, NBT-aware matching, and conditional extraction triggers.

**Key features:**
- Extracts items from an adjacent inventory into the logistics network
- Expanded filter options compared to the basic Extractor Module
- NBT-aware item matching (extracts only specific enchantments, damage values, etc.)
- Conditional extraction — can be triggered by network state or redstone

## Tips

- Use when you need precise control over what gets extracted from a mixed inventory
- NBT matching is useful for extracting only fully repaired tools or specific potion types
- Combine MK3 with a high-tier chassis for maximum throughput on bulk processing lines
