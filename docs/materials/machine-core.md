# Machine Core

The **Machine Core** is a crafting component required to build all RF-powered machines. It is made from [Bronze Ingots](bronze-ingot.md) and Blaze Powder.

**Yields:** 1× Machine Core (8× [Bronze Ingot](bronze-ingot.md) + 1× Blaze Powder)

## Usage

The Machine Core is the central component in all RF-powered machine recipes:

| Machine | Notes |
|---------|-------|
| [Kiln](../automation/kiln.md) | RF-powered smelting furnace |
| [Macerator](../automation/macerator.md) | RF-powered grinding machine |
| [Laser Quarry](../automation/laser-quarry.md) | Automated mining machine |

## Tips

- Craft Machine Cores in batches — each machine requires one and they share the same recipe base
- Bronze Ingots are made from Copper + Tin; you'll need a source of Tin Ore
- Blaze Powder comes from Blaze Rods (dropped by Blazes in the Nether) or can be ground from Blaze Rods in the [Macerator](../automation/macerator.md)
