A right-floated infobox for Logistics blocks, items, tools, machines, and modules.
Replaces the HTML <div class="infobox"> used in the old documentation.

Usage:
 {{Infobox Item
 |name      = Item Extractor Pipe
 |image     = Grid Item Extractor Pipe.png
 |id        = logistics:pipe/item_extractor_pipe
 |type      = Block (Pipe)
 |stackable = Yes (64)
 |tier      = Tier 1 - Mechanical
 |added     = v0.1.0
 }}

All fields except name are optional. Extra optional fields: mod (defaults to
"Logistics"), function, energy, tool. The image looks for an uploaded
[[File:Grid <name>.png]]; see the ''ASSET_UPLOAD_MAP'' reference shipped with the wiki source.
