The '''Satellite Logistics Pipe''' is a [[Logistics Pipes|logistics pipe]] that registers a named destination on the network.

== Usage ==

The Satellite Logistics Pipe registers a named destination so other pipes can route to it by name rather than location. Set a descriptive name in its GUI (e.g. "Iron Storage"); items addressed to that name are deposited into the adjacent inventory. Several satellites can share a name to load-balance deliveries.

== Power ==

Like every [[Logistics Pipes|logistics pipe]], it draws [[RF Energy|RF]] from a connected [[Battery]] — it renders '''green''' while powered and '''red''' when the network has no charge, in which case routing stops and items in transit drop.
