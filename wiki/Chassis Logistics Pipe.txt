The '''Chassis Logistics Pipe''' is a modular [[Logistics Pipes|logistics pipe]] — an empty frame until you install [[Modules]]. Its behavior is entirely defined by the modules it carries, and it comes in five marks (MK1–MK5) that differ only in how many module slots they hold.

== Obtaining ==

=== Crafting ===

Each mark is built from a [[Basic Logistics Pipe]] surrounded by four [[Valves|valves]] — a richer valve for each higher mark:

== Usage ==

A chassis does nothing on its own. Install or swap [[Modules]] with a [[Wrench]]; multiple modules run at once, so one chassis can combine several logistics functions (for example an [[Extractor Module]] plus a [[Provider Module]] in an MK2). Each mark holds one more module slot than the last (MK1 = 1 slot, up to MK5 = 5 slots).

== Power ==

Like every [[Logistics Pipes|logistics pipe]], the chassis draws [[RF Energy|RF]] from a connected [[Battery]] — green while powered, red when the network has no charge.
