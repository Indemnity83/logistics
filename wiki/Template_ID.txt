Renders the '''Data values''' ID table for an item or block — place it under a
"== Data values ==" / "=== ID ===" heading near the bottom of a page, instead of putting the long
namespaced ID in the infobox.

Usage:
 {{ID|logistics:core/tin_ingot}}
 {{ID|logistics:core/tin_ingot|name=Tin Ingot}}

The name defaults to the page title.
