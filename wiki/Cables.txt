'''Cables''' carry [[RF Energy|RF]] power between [[Engines|engines]], [[Batteries|batteries]], and machines, so power can be routed across a distance instead of relying on a direct face-to-face connection. They come in four grades that behave identically apart from how much RF they move per tick.

== Variants ==

Each grade carries twice the RF of the one below it. The three upper cores are [[Caterium|infused alloys]], each made by infusing a dust with a fluid in a [[Transposer]].

== Usage ==

Cables connect to each other and to adjacent power blocks, forming a power network that carries RF from an [[Engines|engine]] to a [[Batteries|battery]], a [[Power Junction]], or a machine. Each grade moves more RF per tick — '''Basic''' 30, '''Conductive''' 60, '''Resonant''' 120, '''Deep''' 240 — but the slowest cable on a run caps its throughput, so match the cable to the demand. Use Basic for short engine-to-battery hops and Deep for long runs or high-demand banks.

A cable never moves more than its grade allows, and RF a machine cannot accept this tick stays in the network. A slow machine at the end of a run throttles delivery to what it can take.

The network serves machines first and storage second. Every machine and [[Power Junction]] on a cable is satisfied before a [[Batteries|battery]] is topped up, and a battery is drawn on only once the generators on that cable are spent. Where several devices sit in the same tier, the tick's budget is split between them in proportion to what each one asks for.

=== Configuration ===

All four throughputs live in <code>config/logistics/power.cables.json</code>, and can be changed in-game with the operator-only <code>/logistics config power.cables &lt;key&gt; &lt;value&gt;</code> command:

{{History|head=1|foot=1|v0.8.11|The cable line was renamed onto the power ladder's tier adjectives and gained a fourth grade.
