'''Logistics Pipes''' are item pipes that join a logistics '''network''': instead of pushing items along at random, they advertise stock, place and fulfill requests, automate crafting, and keep inventories topped up. Every logistics pipe is built on the [[#Basic Logistics Pipe|Basic Logistics Pipe]], draws [[#Power|power]] from a [[Battery]], and connects to the rest of a network through ordinary [[Transport Pipes]].

== Power ==

Logistics pipes are powered. Each draws [[RF Energy|RF]] from a connected [[Battery]]; while powered a pipe renders '''green''', and with no charge it renders '''red''', the network stops routing, and items in transit drop. A single charged Battery on the network keeps every logistics pipe running.

== Usage ==

A logistics network is formed by connecting logistics pipes (through [[Transport Pipes]]) and giving it power. Providers advertise what's available, requesters and suppliers ask for items, and the network uses pathfinding to route each item from a provider to its destination.

=== Basic Logistics Pipe ===

The entry point into the network and the base for every other logistics pipe. It accepts items arriving from the network and deposits them into the first adjacent inventory. Open it with a [[Wrench]] to configure:

* '''Filter (9 slots)''' — restrict which items this pipe accepts; leave empty to accept anything addressed to it.
* '''Default Route''' — when enabled, the pipe catches any item that has run out of other routing options. Keep only '''one''' Default Route pipe per network.

When an item arrives it checks, in order: a filter match → an explicit address to this pipe → Default Route.

=== Provider Logistics Pipe ===

Connects to '''all''' adjacent inventories automatically and, every second, registers their contents with the network. When the network needs an item it can't get elsewhere, the provider extracts it and routes it to the requester. A 9-slot filter (whitelist or blacklist) limits what it offers, and a '''Provider Mode''' controls how much of the inventory is exposed:

{| class="wikitable"
! Mode !! Behavior
|-
| '''Supply''' || Provide all items — the full inventory (default)
|-
| '''Reserve''' || Never extract from the first inventory slot
|-
| '''Guarded''' || Never extract from the first '''and''' last slots
|-
| '''Seeded''' || Always leave 1 item in each slot
|-
| '''Sample''' || Always leave 1 of each item type
|}

=== Requester Logistics Pipe ===

Lets you pull items from the network by hand. Open it with a [[Wrench]] to browse every item available across all providers (searchable, paginated), pick an item and quantity, and the network delivers it into the adjacent inventory. For recurring needs, use a Supplier instead.

=== Supplier Logistics Pipe ===

Keeps an adjacent inventory stocked. It checks the inventory every second against up to 9 supply targets (item + amount) and orders the shortfall from the network, tracking in-transit items so it never over-requests. A '''Supply Mode''' sets the strategy:

{| class="wikitable"
! Mode !! Behavior
|-
| '''Partial''' || Request whatever is available, up to the needed amount (default)
|-
| '''Stocked''' || Only order once stock drops to 50% or below, then request the full shortfall
|-
| '''Infinite''' || Ignore the target; continuously fill all space, one stack at a time
|-
| '''Full''' || Only request if the complete shortfall is available — all-or-nothing
|}

=== Crafting Logistics Pipe ===

Fulfills requests for items that aren't in stock by crafting them. Configure a 3×3 recipe in its GUI; when the output is requested, the pipe pulls the ingredients from providers, crafts, and delivers the result. Chain several to build multi-step crafting trees — one pipe can consume what another produces.

=== Process Logistics Pipe ===

Automates a processing machine (furnace, blast furnace, [[Kiln]], etc.). It feeds raw materials from the network into the machine's input and extracts finished output back into the network, mapping input/output faces and watching machine state so it never overfills. Pair with [[#Provider Logistics Pipe|Providers]] for materials and [[#Requester Logistics Pipe|Requesters]] to pull results.

=== Satellite Logistics Pipe ===

Registers a named destination on the network so other pipes can route to it by name rather than location. Set a descriptive name in its GUI (e.g. "Iron Storage"); items addressed to that name are deposited into the adjacent inventory. Several satellites can share a name to load-balance deliveries.
