The '''Provider Module''' is a [[Chassis Logistics Pipe]] module that advertises adjacent inventory contents to the [[Pipe Networks|logistics network]] and fulfills item requests — the same function as a standalone [[Provider Logistics Pipe]], in module form. A base module can be upgraded to a MkII variant with a higher-tier [[Gears|gear]] for larger quantities per request cycle.

== Obtaining ==

=== Crafting ===

The base module, plus a higher-tier [[Gears|gear]] to upgrade it:

== Usage ==

When installed in a [[Chassis Logistics Pipe]], this module scans adjacent inventories and registers available items with the network. When a [[Requester Logistics Pipe|Requester]] or [[Supplier Logistics Pipe|Supplier]] requests an item, this module extracts it and routes it through the network.

Use this module when you want provider behavior combined with other module functions in the same chassis — for example, extracting from the same inventory with an [[Extractor Module]]. MK2 is worth the upgrade when servicing high-throughput requests, and an optional item filter can restrict which items this module makes available.
