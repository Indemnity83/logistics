Renders a 3×3 crafting-table recipe followed by an arrow and the output item.

Slot parameters are addressed by column (A=left, B=middle, C=right) and row (1=top,
2=middle, 3=bottom). Omit empty slots — they render as blank grid cells.

Usage:
 {{Grid Crafting Table
 |A1=Oak Planks |B1=Glass |C1=Oak Planks
 |Output=Item Extractor Pipe |OutputCount=8
 }}

Parameters:
 A1 B1 C1 / A2 B2 C2 / A3 B3 C3 — item name in each slot (rendered via {{Grid}})
 Output      — the resulting item's name
 OutputCount — quantity produced (optional; omit for 1)

Depends on [[Template:Grid]].
