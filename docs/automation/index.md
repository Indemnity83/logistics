# Automation

Automation machines perform tasks automatically using RF energy.

## Mining
- **[Laser Quarry](laser-quarry.md)** - Automatically mines 16×16 area below, requires RF power

## Processing
- **[Macerator](macerator.md)** - Grinds items into dust; 70+ recipes covering ores, plants, and dyes
- **[Kiln](kiln.md)** - RF-powered electric furnace; processes any vanilla smelting recipe
