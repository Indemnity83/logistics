The '''Active Supplier Module''' is a [[Chassis Logistics Pipe]] module that keeps an adjacent inventory stocked by '''actively requesting items from the [[Pipe Networks|logistics network]]'''. It periodically checks the inventory and places orders with the network's [[Provider Module|providers]] to maintain configured stock levels.

Unlike the [[Passive Supplier Module]] — which only skims items already in transit — the Active variant initiates requests, so it can guarantee replenishment, at the cost of drawing RF from the network [[Battery]] on each supply cycle.

==Behavior==

When installed in a [[Chassis Logistics Pipe]], this module periodically checks the adjacent inventory and requests items from the network to top it up to the configured target levels.

'''Key points:'''
* Actively places orders with network providers — does not wait for passing traffic
* Draws RF from a connected [[Battery]] on each supply cycle
* Stocking modes control how aggressively it orders:
** '''Bulk 50%''' — request in bulk once stock drops to half the target
** '''Partial''' — request whatever is currently available (default)
** '''Full''' — only request when the entire missing amount is available (all-or-nothing)
** '''Bulk 100%''' — request whenever any amount is missing

==Power==

The Active Supplier Module is part of the Tier 3 [[Pipe Networks|logistics network]] and draws RF from a connected [[Battery]] to place its orders. Without a charged Battery it cannot request items. (The [[Passive Supplier Module]] has no such cost.)

==Tips==
* Use for machine input buffers (furnaces, kilns) that must never run dry
* Choose '''Full''' / all-or-nothing mode when partial deliveries would waste a craft
* Combine with a [[Provider Module]] on a nearby chassis to form a closed-loop supply system
