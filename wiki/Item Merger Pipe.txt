The '''Item Merger Pipe''' is a [[Tier System|Tier 1]] mechanical pipe that takes items from any input direction and routes them all to a single configured output direction. It's essential for controlled directional routing.

==Recipe==

{{Grid Crafting Table
|A2=Iron Ingot |B2=Glass |C2=Iron Ingot
|Output=Item Merger Pipe |OutputCount=8
}}

'''Yields:''' 8× Item Merger Pipe

==Behavior==

Item Merger Pipes converge all inputs to a single output. Items can enter from any direction except the output face, and all items exit in the configured output direction.

'''Key features:'''
* All inputs merge to single output
* Output direction configurable with [[Wrench]]
* Items '''cannot''' enter through output face
* Output face marked with '''opaque connector'''
* Guaranteed directional routing (no randomness)

==Configuration==

Use a [[Wrench]] to change the output direction:

# Right-click the pipe with a wrench
# Output direction cycles through available faces
# Output face indicated by '''opaque connector'''
# Items will only exit through this face

==Tips==

* Perfect for collecting from multiple [[Item Extractor Pipe|Item Extractor Pipes]]
* Guarantees items go in one direction (unlike random routing)
* Combine with [[Copper Transport Pipe|Copper Transport Pipes]] for backbone
* Cannot accept items from output direction - plan accordingly
* Use multiple mergers to build tree structures
