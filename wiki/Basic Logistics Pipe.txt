The '''Basic Logistics Pipe''' is the network's sink and the base for every other [[Logistics Pipes|logistics pipe]] — it deposits addressed items into an adjacent inventory.

== Usage ==

The Basic Logistics Pipe is the entry point into the network. It accepts items arriving from the network and deposits them into the first adjacent inventory. Open it with a [[Wrench]] to configure:

* '''Filter (9 slots)''' — restrict which items this pipe accepts; leave empty to accept anything addressed to it.
* '''Default Route''' — when enabled, the pipe catches any item that has run out of other routing options. Keep only '''one''' Default Route pipe per network.

When an item arrives it checks, in order: a filter match → an explicit address to this pipe → Default Route.

== Power ==

Like every [[Logistics Pipes|logistics pipe]], it draws [[RF Energy|RF]] through a [[Power Junction]] — it renders '''green''' while powered and '''red''' when the network has no charge, in which case routing stops and items in transit drop.
