# Bronze Gear

The **Bronze Gear** is a mid-tier crafting component made from [bronze ingots](bronze-ingot.md).

## Recipe
**Crafting:**
- 4× [Bronze Ingot](bronze-ingot.md)
- **Yields:** 1× Bronze Gear

## Uses

Bronze Gears are crafting components for machines and engines (specific uses TBD).

## Progression

Bronze Gears represent mid-tier crafting materials:
- [Wooden Gear](wooden-gear.md) → Basic tier
- [Stone Gear](stone-gear.md) → Stone tier
- [Iron Gear](iron-gear.md) → Mid tier
- [Copper Gear](copper-gear.md) → Mid tier
- [Tin Gear](tin-gear.md) → Mid tier
- **Bronze Gear** → Mid tier (this item)
- [Gold Gear](gold-gear.md) → Advanced tier
- [Diamond Gear](diamond-gear.md) → Advanced tier
- [Netherite Gear](netherite-gear.md) → End tier

## Tips

- Requires bronze ingots (copper + tin alloy)
- Same tier as iron, copper, tin gears
- 1:1 bronze-to-gear ratio (4 ingots = 1 gear)
