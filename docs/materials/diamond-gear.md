# Diamond Gear

The **Diamond Gear** is an advanced-tier crafting component used to create end-game machines and automation equipment. It requires diamonds, making it the most valuable gear type.

## Recipe
**Crafting:**
- 4× Diamond
- **Yields:** 1× Diamond Gear

## Uses

Diamond Gears are used to craft:

**[Laser Quarry](../automation/laser-quarry.md):**
- 1× Diamond Gear required (part of multi-gear recipe)
- Automated mining machine
- Combined with [Iron Gear](iron-gear.md) and [Copper Gear](copper-gear.md)

## Progression

Diamond Gears represent the highest tier of crafting materials:
- [Wooden Gear](wooden-gear.md) → Basic tier
- [Stone Gear](stone-gear.md) → Stone tier
- [Iron Gear](iron-gear.md) → Mid tier
- [Copper Gear](copper-gear.md) → Mid tier
- **Diamond Gear** → Advanced tier (this item)

## Tips

- Most expensive gear - requires diamonds
- Needed for advanced automation (quarry)
- Plan diamond usage carefully
- 1:1 diamond-to-gear ratio (4 diamonds = 1 gear)
- Represents end-game crafting tier
