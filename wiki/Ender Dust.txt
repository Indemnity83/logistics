'''Ender Dust''' is ground from an ender pearl in a [[Macerator]].

== Obtaining ==

=== Grinding ===

{{Grinding|head=1|showname=0|foot=1
|Input=Ender Pearl
|Output=Ender Dust,1
}}

== Usage ==

Ender Dust is not currently consumed by any machine or recipe. It can be stored and piped like any other [[Dusts|dust]], but nothing is built from it.

For ender in a recipe, the mod reaches for [[Liquid Ender]] instead — melted from an {{Mcw|Ender Pearl|ender pearl}} in a [[Crucible]] — which is what infuses [[Echonite Dust]] for the [[Cables|Deep Cable]] and [[Batteries|Deep Battery]].
