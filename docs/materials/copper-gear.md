# Copper Gear

The **Copper Gear** is a mid-tier crafting component used to create advanced machines and automation equipment. It's equivalent in tier to the [Iron Gear](iron-gear.md) but uses copper instead.

**Yields:** 1× Copper Gear (requires [Stone Gear](stone-gear.md))

## Uses

Copper Gears are used to craft:

**[Laser Quarry](../automation/laser-quarry.md):**
- 1× Copper Gear required (part of multi-gear recipe)
- Automated mining machine
- Combined with [Iron Gear](iron-gear.md) and [Diamond Gear](diamond-gear.md)

## Progression

Copper Gears represent mid-tier crafting materials:
- [Wooden Gear](wooden-gear.md) → Basic tier
- [Stone Gear](stone-gear.md) → Stone tier
- [Iron Gear](iron-gear.md) → Mid tier
- **Copper Gear** → Mid tier (this item)
- [Diamond Gear](diamond-gear.md) → Advanced tier

## Tips

- Copper alternative to iron gear
- Needed for advanced automation (quarry)
- Stock up before building large-scale automation
- 1:1 copper-to-gear ratio (4 ingots = 1 gear)
- Equivalent tier to iron gear
