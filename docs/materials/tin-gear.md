# Tin Gear

The **Tin Gear** is a mid-tier crafting component made from [tin ingots](tin-ingot.md). It's equivalent in tier to iron and copper gears.

## Uses

Tin Gears are crafting components for machines and engines (specific uses TBD).

## Progression

Tin Gears represent mid-tier crafting materials:
- [Wooden Gear](wooden-gear.md) → Basic tier
- [Stone Gear](stone-gear.md) → Stone tier
- [Iron Gear](iron-gear.md) → Mid tier
- [Copper Gear](copper-gear.md) → Mid tier
- **Tin Gear** → Mid tier (this item)
- [Bronze Gear](bronze-gear.md) → Mid tier
- [Gold Gear](gold-gear.md) → Advanced tier
- [Diamond Gear](diamond-gear.md) → Advanced tier
- [Netherite Gear](netherite-gear.md) → End tier

## Tips

- Requires tin ingots from [Tin Ore](tin-ore.md)
- Same tier as iron and copper gears
- 1:1 tin-to-gear ratio (4 ingots = 1 gear)
