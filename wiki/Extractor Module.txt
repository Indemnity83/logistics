The '''Extractor Module''' is a [[Chassis Logistics Pipe]] module that actively pulls items from an adjacent inventory and injects them into the [[Pipe Networks|logistics network]]. A base module can be upgraded to MkII and MkIII variants — each a separate upgrade craft with a higher-tier [[Gears|gear]] — pulling more items, more often.

== Usage ==

When installed in a [[Chassis Logistics Pipe]], this module pulls items from an adjacent inventory and routes them into the logistics network. It functions similarly to the standalone [[Item Extractor Pipe]] but is network-aware and can be combined with other modules in the same chassis.

* Extracts items from an adjacent inventory into the logistics network.
* Each mark pulls on its own timer; a single pull spreads its item budget across as many item types as the inventory offers, and takes whatever fits when the pipe is nearly full.
* The MkIII adds a configurable include/exclude item filter — the base module and the MkII have no GUI and pull everything they can reach.
* Can be configured to route extracted items to a specific network destination.

=== Throughput ===

{| class="wikitable"
! Mark !! Items per pull !! Ticks between pulls !! Sustained rate
|-
| Extractor Module || 8 || 80 || 0.1 items/t
|-
| Extractor MkII Module || 8 || 20 || 0.4 items/t
|-
| Extractor MkIII Module || 32 || 10 || 3.2 items/t
|}

Pair it with a [[Provider Module]] in the same chassis to both extract from and advertise one inventory, and reach for the MkIII's filter so only the right items leave a mixed-content chest. The higher marks suit high-output machines (blast furnaces, high-tier kilns) that produce items faster than the base module can keep up with.
