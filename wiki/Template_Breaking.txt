A Minecraft-style breaking-time table for a block and its variants. Times are computed from each
variant's hardness and the tool's mining speed; a row is green when that tool tier can harvest the
block (drops it) and red when it cannot. Powered by [[Module:Breaking]].

Usage:
 {{Breaking
 |tier=stone
 |name1=Tin Ore           |icon1=Grid Tin Ore.png           |hardness1=3
 |name2=Deepslate Tin Ore |icon2=Grid Deepslate Tin Ore.png |hardness2=4.5
 }}

Parameters:
 tool             — correct tool type: pickaxe (default), axe, shovel, hoe, or none
 tier             — minimum tool tier that harvests the block: none, wood, stone, copper, iron,
                    diamond, netherite (default stone)
 toolicon         — icon for the Tool row (default Grid Stone Pickaxe.png)
 nameN/iconN/hardnessN — each block variant (column); add as many as needed
