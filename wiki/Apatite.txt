'''Apatite''' is a gem found underground in the Overworld. It is mined from apatite ore, which drops the gem directly, and is used mainly to craft [[Apatite Valve|apatite valves]] — or ground in a [[Macerator]] for apatite dust.

== Blocks and items ==

* [[File:Grid Apatite Ore.png|24px|link=Apatite Ore]] '''[[Apatite Ore]]''' — an ore found underground that drops apatite when mined
* [[File:Grid Apatite.png|24px|link=Apatite (gem)]] '''[[Apatite (gem)|Apatite]]''' — the gem dropped by apatite ore
* [[File:Grid Apatite Block.png|24px|link=Block of Apatite]] '''[[Block of Apatite]]''' — a block used for compact apatite storage
* [[File:Grid Apatite Dust.png|24px|link=Apatite Dust]] '''[[Apatite Dust]]''' — produced by grinding apatite ore in a [[Macerator]]

== Uses ==

* [[File:Grid Apatite Core.png|24px|link=Cores]] '''[[Apatite Core]]''' — an intermediate component for valve crafting
* [[File:Grid Apatite Valve.png|24px|link=Apatite Valve]] '''[[Apatite Valve]]''' — the gem's main use, crafted via an Apatite Core
