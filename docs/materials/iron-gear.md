# Iron Gear

The **Iron Gear** is a mid-tier crafting component used to create advanced machines and automation equipment. It requires more valuable materials than early-game gears.

**Yields:** 1× Iron Gear (requires [Copper Gear](copper-gear.md))

## Uses

Iron Gears are used to craft:

**[Laser Quarry](../automation/laser-quarry.md):**
- 1× Iron Gear required (part of multi-gear recipe)
- Automated mining machine
- Combined with [Copper Gear](copper-gear.md) and [Diamond Gear](diamond-gear.md)

## Progression

Iron Gears represent mid-tier crafting materials:
- [Wooden Gear](wooden-gear.md) → Basic tier
- [Stone Gear](stone-gear.md) → Stone tier
- **Iron Gear** → Mid tier (this item)
- [Copper Gear](copper-gear.md) → Mid tier
- [Diamond Gear](diamond-gear.md) → Advanced tier

## Tips

- Requires iron - more valuable than wooden/stone gears
- Needed for advanced automation (quarry)
- Stock up before building large-scale automation
- 1:1 iron-to-gear ratio (4 ingots = 1 gear)
