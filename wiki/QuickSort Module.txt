The '''QuickSort Module''' is a [[Chassis Logistics Pipe]] module that '''empties an adjacent inventory''' into the [[Pipe Networks|logistics network]], sending each stack to a sink whose filter accepts it.

== Obtaining ==

=== Crafting ===

{{Crafting|head=1|foot=1|showname=0
|A1=Light Blue Dye |B1=Diamond Gear |C1=Light Blue Dye
|A2=Redstone |B2=Blank Module |C2=Redstone
|A3=Light Blue Dye |B3=Redstone |C3=Light Blue Dye
|Output=QuickSort Module
}}

The matching [[Chipsets|chipset]] can replace the gear — use a [[Diamond Chipset]] in place of the [[Diamond Gear]] to craft it with a [[Sequential Fabricator]].

== Usage ==

When installed in a [[Chassis Logistics Pipe]], the QuickSort Module scans the inventory next to the chassis and pulls out one stack at a time. Each stack goes to the network sink with an item filter that matches it, such as an [[ItemSink Module]] or [[Terminus Module]], chosen by [[Modules#Sink priority|sink priority]].

* Sends a stack every 6 ticks while it finds items it can route.
* Never sends to a default route; items with no matching filtered sink stay in the inventory.
* When it finds nothing to route, it slows to one attempt every 24 ticks until something changes.
* Has no GUI and no configuration.

Place it on a chest that collects mixed items, such as a mob farm's output, and set up filtered sinks for the items you want sorted out of it.
