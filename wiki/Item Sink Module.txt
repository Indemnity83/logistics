The '''Item Sink Module''' is a [[Logistics Pipes#Chassis Logistics Pipe|Chassis Logistics Pipe]] module that accepts a '''specific configured item type''' from the [[Pipe Networks|logistics network]] and deposits it into an adjacent inventory. It is the module-form equivalent of a [[Basic Logistics Pipe]] with a strict item filter.

== Usage ==

When installed in a [[Logistics Pipes#Chassis Logistics Pipe|Chassis Logistics Pipe]], this module registers itself as a delivery destination for a configured item type. Network items of the matching type are routed to this chassis and deposited into an adjacent inventory.

* Accepts one configured item type from the network.
* Deposits received items into an adjacent inventory.
* Multiple Item Sink Modules can be installed in a single chassis (using multiple module slots) to accept multiple item types.
* Does not accept unconfigured or non-matching items.

=== Configuration ===

Use a [[Wrench]] to open the chassis GUI, then configure the module:

'''Target item slot:''' Place the item type this module should accept. Only items matching this type will be routed here.

=== Tips ===

* Install multiple Item Sink Modules in one chassis to create a multi-item sorting station in a single pipe.
* Use alongside a [[Quicksort Module]] for a tiered approach: quicksort handles known items, Item Sink catches the rest.
* Leave adjacent storage slots pre-stocked with the target item to help the module recognize the correct inventory slot.
