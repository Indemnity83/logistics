Renders the '''Data values''' ID table (Name / Namespaced ID / Translation key). Pass each row's
namespaced ID and translation key as literal strings — take the key from the lang file, don't infer
it. Supports up to five rows for multi-variant blocks.

Usage:
 {{ID|logistics:core/tin_ingot|item.logistics.core.tin_ingot}}
 {{ID
 |logistics:core/tin_ore|block.logistics.core.tin_ore
 |name2=Deepslate Tin Ore|logistics:core/deepslate_tin_ore|block.logistics.core.deepslate_tin_ore
 }}

Parameters:
 1, 2          — row 1 namespaced ID and translation key
 name          — row 1 display name (defaults to the page title)
 3/4 + name2   — optional row 2; 5/6 + name3, 7/8 + name4, 9/10 + name5 — optional rows 3-5
