# Bronze Ingot

**Bronze Ingot** is an alloy created from copper and tin. It's used for bronze valves and gears.

## Recipe

**Alloy Crafting:**
- Copper Ingot + [Tin Ingot](tin-ingot.md) → Bronze Ingot
- (Exact recipe TBD - likely vanilla crafting or smelting)

**Crafting (from block):**
- 1× Bronze Block → 9× Bronze Ingot

## Usage

**[Kiln](../automation/kiln.md) Crafting:**
- [Bronze Valve](valve-bronze.md) - 5× bronze ingot required

**Gears:**
- [Bronze Gear](bronze-gear.md) - 4× bronze ingot

**Storage:**
- 9× Bronze Ingot → Bronze Block

## Tips

- Alloy of copper + tin
- Used for mid-tier components
- Bronze valve requires blaze rod/lava fuel
- Stock up for mid-tier progression
