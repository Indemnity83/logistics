The '''Quicksort Module''' is a [[Chassis Logistics Pipe]] module that '''automatically sorts items''' into designated storage locations within the [[Pipe Networks|logistics network]]. It scans available storage and routes items to inventories that already contain matching item types.

== Obtaining ==

=== Crafting ===

{{Crafting|head=1|foot=1|showname=0
|A1=Light Blue Dye |B1=Diamond Gear |C1=Light Blue Dye
|A2=Redstone |B2=Blank Module |C2=Redstone
|A3=Light Blue Dye |B3=Redstone |C3=Light Blue Dye
|Output=Quicksort Module
}}

The matching [[Chipsets|chipset]] can replace the gear — use a [[Diamond Chipset]] in place of the [[Diamond Gear]] to craft it with a [[Sequential Fabricator]].

== Usage ==

When installed in a [[Chassis Logistics Pipe]], the Quicksort Module intercepts items arriving at the chassis from the network and intelligently routes each item to a storage location that already holds that item type. This fills existing stacks before opening new storage slots, keeping your network organized automatically.

* Routes items to existing partial stacks of the same type.
* Reduces storage fragmentation by consolidating item types.
* Requires [[Provider Logistics Pipe|Provider Logistics Pipes]] nearby to know where items are stored.
* Items with no existing storage destination fall through to the default route.

Place it in a chassis near your main storage array so items are sorted as they arrive; it works best with a well-organized system where each inventory holds one item category. Add an [[Item Sink Module]] as a fallback so items with no existing home don't simply land on the default route.
