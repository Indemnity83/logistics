Renders the '''Data values''' ID table for an item or block (Name / Namespaced ID / Translation
key) — place it under a "== Data values ==" / "=== ID ===" heading near the bottom of a page,
instead of putting the long namespaced ID in the infobox.

Both the namespaced ID and the translation key are passed as literal strings (don't infer the key
— take it from the lang file).

Usage:
 {{ID|logistics:core/tin_ingot|item.logistics.core.tin_ingot}}
 {{ID|logistics:automation/kiln|block.logistics.automation.kiln|name=Kiln}}

Parameters:
 1     — the namespaced ID
 2     — the translation key (literal lang key)
 name  — display name (defaults to the page title)
