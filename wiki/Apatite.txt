'''Apatite''' is a gem found underground in the Overworld. It is mined from apatite ore, which drops the gem directly, and is used to craft [[Apatite Valve|apatite valves]] — or ground in a [[Macerator]] for apatite dust.

== Blocks and items ==

* [[File:Grid Apatite Ore.png|24px|link=Apatite Ore]] '''[[Apatite Ore]]''' — an ore found underground that drops apatite when mined
* [[File:Grid Apatite.png|24px|link=Apatite (gem)]] '''[[Apatite (gem)|Apatite]]''' — the gem dropped by apatite ore
* [[File:Grid Block of Apatite.png|24px|link=Block of Apatite]] '''[[Block of Apatite]]''' — a block used for compact apatite storage
* [[File:Grid Apatite Dust.png|24px|link=Apatite Dust]] '''[[Apatite Dust]]''' — produced by grinding apatite ore in a [[Macerator]]

== Uses ==

* [[File:Grid Apatite Valve.png|24px|link=Apatite Valve]] '''[[Apatite Valve]]''' — the gem's main use, a fluid-network valve crafted from apatite

== Mod compatibility ==

Apatite is published as <code>#c:gems/apatite</code>, with the ore, storage block and dust under <code>#c:ores/apatite</code>, <code>#c:storage_blocks/apatite</code> and <code>#c:dusts/apatite</code>, so other mods can see and use it. See [[Mod Compatibility]].
