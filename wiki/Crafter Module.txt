The '''Crafter Module''' is a [[Chassis Logistics Pipe]] module that enables '''automated crafting''' within a chassis pipe. When installed, the chassis can fulfill network requests for a specific crafted item by sourcing ingredients from the network and performing the crafting operation. Three mark variants exist (MK1/II/III), with higher marks supporting more complex recipes or faster crafting cycles.

== Obtaining ==

=== Crafting ===

The three marks share a recipe, differing only by the [[Chips|chip]] — higher marks handle more demanding crafting workloads:

== Usage ==

When installed in a [[Chassis Logistics Pipe]], this module registers a crafting recipe with the network. When the network receives a request for the output item, this module requests the necessary ingredients from the network's providers and performs the crafting operation, delivering the result to the requester.

* Registers a crafting recipe with the logistics network.
* Automatically requests ingredients from [[Provider Logistics Pipe|Provider Logistics Pipes]] or [[Provider Module|Provider Modules]].
* Delivers crafted output back into the network or to a configured destination.
* Multiple Crafter Modules in different chassis pipes can produce the same item — the network balances the load.

Combine a Crafter Module with a [[Provider Module]] in one chassis for a station that both produces and provides items, and chain crafters so one module's output feeds another's recipe for multi-step production. Higher marks are worthwhile for high-demand recipes where crafting speed matters.
