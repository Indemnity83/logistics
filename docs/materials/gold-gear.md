## Progression

Gold Gears represent advanced-tier crafting materials:
- [Wooden Gear](wooden-gear.md) → Basic tier
- [Stone Gear](stone-gear.md) → Stone tier
- [Iron Gear](iron-gear.md) → Mid tier
- [Copper Gear](copper-gear.md) → Mid tier
- [Tin Gear](tin-gear.md) → Mid tier
- [Bronze Gear](bronze-gear.md) → Mid tier
- **Gold Gear** → Advanced tier (this item)
- [Diamond Gear](diamond-gear.md) → Advanced tier
- [Netherite Gear](netherite-gear.md) → End tier

## Tips

- Requires gold ingots
- More valuable than iron/copper/tin gears
- 1:1 gold-to-gear ratio (4 ingots = 1 gear)
