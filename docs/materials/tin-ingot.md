# Tin Ingot

**Tin Ingot** is a metal obtained by smelting [raw tin](tin-ore.md). It's used to create bronze alloy and tin-based components.

## Recipe

**Smelting:**
- Raw Tin (from [Tin Ore](tin-ore.md)) → Tin Ingot
- Furnace or blast furnace

**Crafting (from block):**
- 1× Tin Block → 9× Tin Ingot

## Usage

**Bronze Alloy:**
- Tin + Copper → [Bronze Ingot](bronze-ingot.md)

**[Kiln](../automation/kiln.md) Crafting:**
- [Tin Valve](valve-tin.md) - 5× tin ingot required

**Gears:**
- [Tin Gear](tin-gear.md) - 4× tin ingot

**Storage:**
- 9× Tin Ingot → Tin Block

## Tips

- Common metal, easy to obtain
- Essential for bronze production
- Needed for tin valve crafting
- Stock up for gear and valve production
