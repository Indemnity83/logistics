The '''Fluid Supplier Module''' is a [[Chassis Logistics Pipe]] module that keeps an adjacent machine's fluid tank stocked by ordering [[Fluid Packet|fluid packets]] from the network — the same function as a standalone [[Fluid Supplier Pipe]], in module form.

== Obtaining ==

=== Crafting ===

{{Crafting|head=1|foot=1|showname=0
|A1=Light Blue Dye |B1=Iron Gear |C1=Light Blue Dye
|A2=Redstone |B2=Blank Module |C2=Redstone
|A3=Light Blue Dye |B3=Redstone |C3=Light Blue Dye
|Output=Fluid Supplier Module
}}

The matching [[Chipsets|chipset]] can replace the gear — use an [[Iron Chipset]] in place of the [[Iron Gear]] to craft it with a [[Sequential Fabricator]].

== Usage ==

When installed in a [[Chassis Logistics Pipe]], set its fluid filter by right-clicking it with a bucket of the target fluid, then configure a target amount through the pipe's [[Wrench|wrench]]-opened GUI — the same '''Target''', '''Fulfillment''', and '''Min. Threshold''' controls as the standalone [[Fluid Supplier Pipe]]. It orders the shortfall as fluid packets and deposits paid-off fluid into the adjacent tank.

Use this module when you want fluid-supplying behavior combined with other module functions in the same chassis.
