The '''Satellite Logistics Pipe''' is a [[Tier System|Tier 3]] network logistics pipe that acts as a '''named remote destination'''. It gives a pipe location a network-addressable name so that other pipes — particularly [[Chassis Logistics Pipe|Chassis Logistics Pipes]] with routing modules — can send items to it by name rather than by physical proximity.

==Recipe==

{{Grid Crafting Table
|A1=Lapis Valve |B1=Basic Logistics Pipe |C1=Lapis Valve
|Output=Satellite Logistics Pipe
}}

'''Yields:''' 1× Satellite Logistics Pipe (2× [[Lapis Valve]] + 1× Basic Logistics Pipe)

==Behavior==

The Satellite Logistics Pipe registers itself with the [[Pipe Networks|logistics network]] under a configurable name. Other network pipes can route items to this pipe by referencing its satellite name. This decouples routing logic from physical location — you can move storage and the sending pipes simply continue routing to the same named destination.

'''Key features:'''
* Registers a named destination on the logistics network
* Accepts items routed to it by name from other network pipes
* Deposits received items into an adjacent inventory
* Configurable name via GUI
* Multiple satellite pipes can share a name to distribute delivery across multiple inventories

==Configuration==

Use a [[Wrench]] to open the GUI:

'''Satellite name:''' Enter a text name for this destination. Any pipe on the network that references this name will route items here.

'''Filter slots:''' Optionally restrict which items this satellite accepts to prevent misrouted items from landing in the wrong inventory.

==Tips==

* Use descriptive names ("Iron Storage", "Fuel Chest", "Overflow") to keep large networks readable
* Multiple Satellite Pipes with the same name act as load-balanced destinations — the network distributes items across all matching satellites
* Rename a satellite when reorganizing storage without needing to reconfigure every sending pipe
* Combine with [[Process Logistics Pipe|Process Logistics Pipes]] to deliver machine outputs to named satellite destinations

==Power==

As a [[Tier System|Tier 3]] network pipe, this draws [[RF Energy|RF]] from a connected [[Battery]]. Without a charged Battery the network stops routing and drops in-transit items; the pipe renders '''green when powered''' and '''red when not'''.
