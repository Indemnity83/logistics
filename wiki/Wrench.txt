The '''Wrench''' is a configuration tool for pipes, engines, and machines. Use it to rotate output faces, select extraction directions, open filter GUIs, and reset overheated engines.

== Obtaining ==

=== Crafting ===

{{Grid Crafting Table
|A1=Iron Ingot |C1=Iron Ingot
|B2=Iron Ingot
|B3=Iron Ingot
|Output=Wrench
}}

'''Yields:''' 1× Wrench

== Usage ==

Right-click a block with the wrench to configure it; different blocks respond differently. The wrench is non-destructive — it never breaks a block (sneak to break normally), so it can stay in your hotbar while you build.

=== Configuring pipes ===

* '''[[Item Merger Pipe]]''' — cycles the output direction. Items exit only through the configured face, marked by an opaque connector.
* '''[[Item Extractor Pipe]]''' — cycles the extraction face. Only one face extracts at a time, marked by an opaque connector.
* '''[[Item Filter Pipe]]''' — opens the filter configuration GUI, where you set which items route to which faces (per-side filters).

=== Configuring engines ===

* '''[[Redstone Engine]] / [[Stirling Engine]]''' — rotates the RF output face. The output face must touch the machine's input for power to transfer, so position the engine accordingly.
* '''[[Stirling Engine]] overheat reset''' — right-click an overheated engine to reset it, letting it cool and restart. This is required after an overheat shutdown.

=== Other blocks ===

The wrench works with any configurable Logistics block; future machines and components will use it for configuration as well.

=== Inspecting blocks ===

The wrench itself is for configuration only, not inspection. Hover information comes through '''[https://www.curseforge.com/minecraft/mc-mods/jade Jade]''' HUD integration, which displays:

* Pipe contents (items currently inside a pipe)
* Pipe module status (installed modules in a [[Chassis Logistics Pipe]])
* Machine progress (Kiln, Macerator, Laser Quarry, etc.)
* Power and energy diagnostics

Install Jade alongside Logistics to read this information by simply looking at a block.
