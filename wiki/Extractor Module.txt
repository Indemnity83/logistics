The '''Extractor Module''' is a [[Chassis Logistics Pipe]] module that actively pulls items from an adjacent inventory and injects them into the [[Pipe Networks|logistics network]]. A base module can be upgraded to MkII and MkIII variants — each a separate upgrade craft with a higher-tier [[Gears|gear]] — extracting at greater speed or quantity.

== Usage ==

When installed in a [[Chassis Logistics Pipe]], this module pulls items from an adjacent inventory and routes them into the logistics network. It functions similarly to the standalone [[Item Extractor Pipe]] but is network-aware and can be combined with other modules in the same chassis.

* Extracts items from an adjacent inventory into the logistics network.
* Configurable item filter — extract only specific item types.
* Higher mark variants extract faster or in larger quantities per tick.
* Can be configured to route extracted items to a specific network destination.

Pair it with a [[Provider Module]] in the same chassis to both extract from and advertise one inventory, and set the item filter so only the right items leave a mixed-content chest. The higher marks suit high-output machines (blast furnaces, high-tier kilns) that produce items faster than an MK1 can keep up with.
