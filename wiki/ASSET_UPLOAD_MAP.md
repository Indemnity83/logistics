# Asset Upload Map

The wiki's `{{Grid}}` and `{{Infobox Item}}` templates look up images named
`File:Grid <Item Name>.png`. The mod icons in `docs/assets/icons/` must be uploaded
to the wiki under those names. This table maps each source icon to its target File name.

Until an image is uploaded, `{{Grid}}` falls back to a plain text link, so pages still work.
