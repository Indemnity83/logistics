The '''Blank Module''' is the base crafting component for all [[Modules|modules]]. It has no behavior on its own — it is only used as an ingredient in module recipes. Every module type is crafted by combining a Blank Module with specific materials in the crafting grid, then installed into a [[Chassis Logistics Pipe]].

== Usage ==

The Blank Module is consumed when crafting any other module type. Craft it in batches so you have a supply ready when building out your [[Chassis Logistics Pipe]] setup — each module type requires one, and a fully loaded chassis needs several. {{Mcw|Paper}} is plentiful from sugar cane, and gold nuggets come from gold ingots (nine per ingot).
