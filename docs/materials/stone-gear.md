# Stone Gear

The **Stone Gear** is a stone-tier crafting component used to create more advanced machines and engines. It represents progression beyond wooden-tier components.

## Recipe
**Crafting:**
- 4× Cobblestone (or Stone)
- **Yields:** 1× Stone Gear

## Uses

Stone Gears are used to craft:

**[Stirling Engine](../power/stirling-engine.md):**
- 2× Stone Gear required
- High-power fuel-burning engine
- Major upgrade from [Redstone Engine](../power/redstone-engine.md)

## Progression

Stone Gears represent the second tier of crafting materials:
- [Wooden Gear](wooden-gear.md) → Basic tier
- **Stone Gear** → Stone tier (this item)
- [Iron Gear](iron-gear.md) → Mid tier
- [Copper Gear](copper-gear.md) → Mid tier
- [Diamond Gear](diamond-gear.md) → Advanced tier

## Tips

- Craft from common cobblestone or stone
- Needed for Stirling Engine (better than Redstone Engine)
- Stock up before building power infrastructure
- Simple 1:1 cobblestone-to-gear ratio
