This template renders a single inventory item: its grid icon (linked to the item's page),
with an optional count.

Usage:
 {{Grid|Iron Ingot}}      -> icon linking to [[Iron Ingot]]
 {{Grid|Iron Ingot|8}}    -> icon + "×8"

Image lookup: it looks for [[File:Grid <name>.png]]. If that image has not been
uploaded yet, it falls back to a plain text link to the item's page, so the template
degrades gracefully on a fresh wiki. See the ''ASSET_UPLOAD_MAP'' reference shipped with
the wiki source for the upload naming convention.
